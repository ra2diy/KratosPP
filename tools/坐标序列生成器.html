Vector 序列生成器

坐标纸用 xy（右为 x+，上为 y+）输入；输出自动换算为 F = y、L = −x 的坐标值。 每点生成一段完整 section：统一配置 + 「标签名=F,L,H」（标签名在下方可填，如 Vector.TargetFLH / AutoWeapon.TargetFLH）；段间可按点顺序串 Next 链（可勾选开关，末段不写）。
添加模式：点击 + 号光标处即加一个点（追加到末尾）。
选择模式：点选某个点后可拖动位置，按 Delete 删除；列表里可上移/下移调整顺序。
插队：先选中一个点，再点【插队】，然后点击坐标纸 → 新点插到该点之后，插完自动退出插队模式（再点一次按钮或按 Esc 可取消）。
坐标纸 1 格 = 256 lepton，原点居中，视野 ±2560 lepton。
绘制连线：按点顺序把相邻点连起来并标出走向箭头，纯预览，不写入 INI（可随时关闭）。
旋转模式：选中一个组后进入本模式，拖动鼠标即绕原点旋转整组（吸附角在右侧填，0 = 自由旋转）。
预设点：右侧填边数与半径 → 【预览】只看形状（空心点+虚线轮廓）→ 【生成编组】才真正落点；成组后拖一个点 = 整组平移，Delete = 删整组，点【解组】后各点独立。
Ctrl + 点击 = 多选（点组内点则整组进出选择集），选好至少 2 个后点【编组】把它们合成一组（可跨组/独立点混选）；解组点工具栏按钮（也可点列表组行里的【解组】），编组/解组随时自由来回。

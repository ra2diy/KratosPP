# Kratos++ 使用文档

> 面向 MOD 制作者：如何安装 Kratos++、在 INI 中声明新功能、使用 AE 附着效果系统。
> 完整标签清单以 `附件包/Kratos食用说明书.ini`（约 2000 行）为准，本文是入口指南与索引。

## 1. 简介

Kratos++ 是《尤里的复仇》的引擎扩展平台（DPKratos 的 C++ 移植版）。它以 `Kratos.dll` 随游戏启动，通过 INI 标签为 MOD 提供替身、AE 附着效果、反抛射体、礼盒、Vector 位移等新玩法，不修改原版游戏文件。

功能特性：

- 无需编程，全部通过 INI 标签使用；
- 支持与 Ares、Phobos 同时使用（个别重叠功能提供开关）；
- 提供替身（Stand）、礼盒（GiftBox）、反抛射体（AntiMissile）、区域警戒巡航、伤害/血量数字显示等大量功能；
- 支持存读档（版本号校验）。

## 2. 安装

### 2.1 前置要求

- 一份可正常运行的《尤里的复仇》（YR 1.001）游戏目录；
- 推荐配合 Ares（`RunAres.bat` 启动）；
- 若使用 Phobos，注意与 Kratos 的功能重叠项（见 3.3）。

### 2.2 安装步骤

1. 从 [Release](https://github.com/ChrisLv-CN/KratosPP/releases) 下载最新压缩包；
2. **如果之前使用过 DPKratos，务必先彻底删除**：
   - 文件夹 `DynamicPatcher`
   - `DynamicPatcher.dll`
   - `DynamicPatcher_RELEASE.dll`
   - `PatcherLoader.dll`
3. 把 `Kratos.dll`（及可选 `Kratos.pdb`）放入游戏根目录；
4. 为 `gamemd.exe` 与 `syringe.exe` 添加管理员权限（右键属性 → 兼容性 → 以管理员身份运行）；
5. 用 `RunAres.bat` 启动游戏（或按你的 Ares/Phobos 注入方式启动）；
6. 进入游戏后侧边栏底部显示 Kratos 版本号即安装成功。

### 2.3 卸载

删除游戏目录下的 `Kratos.dll` 即可；Kratos 不修改原版文件，不会残留其他文件。

## 3. 兼容性说明

### 3.1 与 DPKratos

两者互斥，**不能共存**。使用前必须删除 DPKratos 的全部文件。

### 3.2 与 Ares / Phobos

- 大部分功能可与 Ares、Phobos 并存；
- 重叠功能以"开关"形式提供，默认通常由 Kratos 接管（如碎片逻辑、动画伤害、Phobos 影子缩放）；
- 例：`[CombatDamage]AllowAnimDamageTakeOverByKratos=no` 可让 Ares 继续管理动画伤害；`[AudioVisual]AllowTakeoverPhobosShadowMaker=no` 可让 Phobos 管理影子。

### 3.3 免责声明

- 部分功能为实验性，可能不稳定；
- 联机环境有较高概率出现不同步/崩溃，请自行测试；
- 严禁用于商业对战平台（如"小偷公司兰博玩"）或修改他人 MOD 牟利。

## 4. 快速开始

在 `rulesmd.ini` 中新增段落并引用：

```ini
[AudioVisual]
AllowTakeoverPhobosShadowMaker=yes

[TechnoType]
SelectWeaponUseRange=yes

; 为某单位启用反抛射体
[SomeUnit]
AntiMissile.Enable=yes
AntiMissile.OneShotOneKill=yes
```

## 6. AE 附着效果系统

AE（AttachEffect）是 Kratos++ 的核心玩法框架：给单位/抛射体"附加一段带寿命、带条件、带多个子效果"的 Buff。

### 6.1 基本结构

```ini
[MyBuffAE]                    ; 任意唯一段名
Duration=300                  ; 持续时间（帧），-1 = 永久
InitialDelay=0                ; 生效前延迟
Animation.Type=ANIM1          ; 效果器 1：播放动画
AutoWeapon.Type=Weapon1       ; 效果器 2：自动武器
Stand.Type=SomeUnit           ; 效果器 3：替身
```

### 6.2 通用标签（AE 本体）

| 标签 | 默认 | 说明 |
| --- | --- | --- |
| `Duration` | -1 | 持续帧数，-1 永久 |
| `InitialDelay` / `InitialRandomDelay` | -1 / 0,0 | 初始延迟/随机延迟 |
| `Delay` / `RandomDelay` | 0 / 0,0 | 同名 AE 重复获得的冷却 |
| `DiscardOnEntry` | no | 离开地图失效 |
| `DiscardOnTransform` | yes | 变身失效 |
| `DiscardOnUndeploying` / `DiscardOnSelling` | no | 反部署/出售失效 |
| `TreatSellingAsDeath` | yes | 建筑出售视为死亡 |
| `StartAfterBuildup` | yes | 建筑拔起期间不生效 |
| `Cumulative` | NO | 叠加模式：NO/YES/ATTACKER/HOUSE |
| `MaxStack` | -1 | 叠加上限 |
| `Group` | 空 | 分组，同组互斥/增减时长 |
| `Next` | 空 | 结束后附加的下一个 AE |
| `AttachWithOutTypes` | 空 | 存在这些 AE 时不可附加 |
| `Inheritable` | yes | 可被礼盒继承 |
| `AttachNeedMoney` / `ReceiverNeedMoney` | 0 | 来源/接受者金钱要求 |

### 6.3 效果器（Effect）清单

效果器写在 AE 段内，前缀为效果器名，如 `Animation.Type=...`：

| 效果器 | 说明 |
| --- | --- |
| `Animation` | 播放动画 |
| `AutoWeapon` | 自动使用指定武器攻击（含加权随机/FromWarhead 等模式） |
| `Broadcast` | 广播信息/标记 |
| `Counter` | 计数器（受击计数、触发阈值） |
| `CountTrigger` | 达到计数触发事件 |
| `Ammo` / `AmmoTrigger` | 操作弹药计数器（护盾/计数模式） |
| `DamageSelf` | 对自身造成伤害 |
| `ExtraFire` | 额外开火 |
| `FireSuper` | 发射超级武器 |
| `Host` | 刷兵（含 `Host.Dynamic` 动态类型） |
| `Immune` | 免疫（伤害/状态等） |
| `Info` | 显示信息/图标 |
| `Mark` | 打标记（配合过滤） |
| `Revenge` | 复仇（受击后触发） |
| `Stack` | 叠层计数（可探测任务类型 `WatchMission`） |
| `Stand` | 替身（含火车替身） |
| `Vector` | 位移控制（Force/Freeze/Circle/MoveTo 等） |
| `TurretSpin` / `BodySpin` | 炮塔/车身旋转 |
| `Vampire` | 吸血 |
| `CrateBuff` | 箱子增益统计 |
| `AttackBeacon` | 攻击信标 |

### 6.5 AE 的赋予方式

1. **弹头附加**：在 `[WarheadType]` 段写：

   ```ini
   AttachEffectTypes=MyBuffAE
   AttachEffectChances=100% ; 附加概率
   ```

2. **单位自带**：在单位段落写 `AttachEffectTypes=...`（支持 `AttachOnceInTechnoType=yes` 只在创建时附加一次）；

3. **武器反馈**：武器命中后把 AE 附加给攻击者（`FeedbackAttach` 逻辑，配合 `[WeaponType]` 标签）；

4. **AE 连锁**：`Next=OtherAE` 在结束时附加；

5. **乘客**：载具乘客通过 `AEMode` 组序号附加（`AttachByPassenger` 控制）。

## 7. 常用功能示例

### 7.1 替身（Stand）

```ini
[StandAE]
Duration=-1
Stand.Type=HTNK
Stand.Offset=0,-100,0
Stand.IsTrain=no
Stand.SameHouse=yes
```

### 7.2 反抛射体（AntiMissile）

```ini
[AntiMissileUnit]
AntiMissile.Enable=yes
AntiMissile.ScanAll=yes
AntiMissile.Range=8
AntiMissile.OneShotOneKill=yes

[SomeProjectile]
Interceptable=yes
Strength=50
```

### 7.3 区域警戒巡航（Fighter.AreaGuard）

```ini
[Raptor]
Fighter.AreaGuard=yes
Fighter.GuardRange=10
Fighter.AutoFire=yes
```

### 7.4 飞行器俯冲

```ini
[Aircraft]
Dive=yes
Dive.FlightLevel=520
Dive.HeadToTarget=yes
```

### 7.5 伤害/血量数字显示

```ini
[AudioVisual]
HealthText.Enable=yes
DamageText.Enable=yes
HealthText.UseSHP=yes
HealthText.SHP=pipsnum.shp
```

### 7.6 弹药护盾（Ammo）

```ini
[AmmoShieldAE]
Duration=-1
Ammo.Num=5
Ammo.ReactionMode=SHIELD
```

## 9. 日志与故障排查

### 9.1 日志文件

- `debug.log`：运行日志（游戏根目录，复用游戏日志系统，Release/Debug 均输出）；
- Debug 构建另有控制台窗口。

### 9.2 常见问题

**Q：进游戏没有版本号？**
A：确认 `Kratos.dll` 在游戏根目录、`gamemd.exe`/`syringe.exe` 有管理员权限、用 `RunAres.bat` 或等效注入方式启动；检查是否残留 DPKratos 文件。

**Q：标签无效？**
A：确认标签拼写、所属段落、大小写前缀（如 `Animation.Type` 而不是 `AnimationType`）；查看 `debug.log` 是否有解析失败提示。

**Q：联机不同步/崩溃？**
A：Kratos 部分功能为实验性；用 `-SYNCLOG` 参数启动并反馈日志给作者。

**Q：与 Phobos 同用时某个功能不对？**
A：相关功能在 `[CombatDamage]` / `[AudioVisual]` 下有接管开关，检查并调整。
